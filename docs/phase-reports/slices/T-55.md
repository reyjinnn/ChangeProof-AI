## Oracle isolation — access matrix (code inspection)

Claim under test: **no arm (B0/B1/B2/Full/ablations) reaches hidden oracle content, expected patch, or Full trace.**

| Mechanism | Location | Effect |
|-----------|----------|--------|
| Proposer projection strips bindings | `roles.ts` proposerCases | arms see dev cases only, no `oracleRef`/`referenceDigest`; holdout never projects |
| Store role check | `store.ts` get | holdout bytes refuse proposer reads even by digest; unknown digests refused |
| Oracle by reference only | `readiness.ts` EvalCase | case records carry `oracleRef` identity string; oracle CONTENT exists nowhere in the module |
| Comparisons carry aggregates | `reduce.ts` | serialized comparisons contain counts/costs only (pinned by t33-roles leak test) |
| Injection-only execution | `runner.ts` runArm | oracle content is never loaded, so no injected runner can receive it from this module |

Gaps (honest, proposed fixes belong to owning phases — NOT edited here):

1. **Role is caller-chosen.** `runArm({role})` trusts the caller; a caller passing `'evaluator'` for a proposer runner hands holdout bytes to that runner. No orchestrator wiring of `runArm` exists in `src` yet (only tests call it), so the trusted call-site convention is unwritten. Owner: WP3-13/orchestrator wiring.
2. **Access matrix is declarative.** `allowedTools`/`allowedInputs`/`feedbackDisclosure` are schema fields nothing in `src` consumes at execution time; per-arm tool/data/feedback enforcement must live in the (not yet built) arm-execution harness. Owner: WP3-13.
3. **Identity by assertion.** `evaluatorIdentity`/`oracleIdentity`/`configDigest` are strings compared for equality only; nothing binds them cryptographically to the real evaluator binary, oracle bytes, or run config. Owner: WP3-13 (freeze ceremony).
4. **Full-trace non-disclosure is procedural.** No trace store exists in the module (good — nothing to leak), but keeping Full traces out of baseline prompts depends on the future arm harness honoring the frozen access matrix. Owner: WP3-13.

Net: within the existing module, oracle leakage is structurally impossible (no oracle content present); end-to-end enforcement across the future live arm harness is NOT yet built. Slice verdict on the fail condition: **no reachable-oracle path exists in current code; live-arm enforcement remains open work.**
